# 个人网申助手第一阶段设计

用户已授权常规可逆开发自主推进。开发、构建、测试仅在开发主机执行，全部文件在本项目下。原会话不恢复。

## 选择
采用 OpenJobAutofill 的 MIT 源码作为独立扩展基础，保留许可证；另建 Java 21 + Spring Boot 规则服务。现有根目录打包扩展没有开发源码，也未核实再分发许可证，保留原样，不纳入 Git。全部重写成本较高，暂不采用。

## 数据与操作
profileV2、规则缓存和可选 AI 配置各自存于 chrome.storage.local；免账号。导出备份仅含资料，不含 API 密钥。AI 默认关闭，只有明确启用后才走原来的 AI 增强；默认流程不产生 AI 网络请求。预览后由用户确认填写，已有非空内容保护，并在实际写入前再次核对；最终提交、上传附件和法律声明交给用户。

## 规则服务
GET /api/v1/rules 返回有版本的字段别名和站点配置；GET /api/v1/health 返回状态。无个人资料写入接口，无数据库。默认监听 127.0.0.1:18765。扩展自带规则，手动从本地服务更新并缓存，失败保留旧规则。配置只含声明式数据，不执行下载代码。

## 验证
用虚构资料验证原版默认 AI 请求问题；改造版验证零 AI 请求、原生及受控输入事件、多段教育、既有值保护、预览取消、导入导出、后端正常和离线回退。自动化在独立浏览器资料目录运行，不读取用户浏览器资料。真实招聘站点未测试前不宣称覆盖。
