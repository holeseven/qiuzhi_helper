# 规则服务与离线策略

作者：lxy。

唯一规则源为 `extension/config/default-rules.json`；Maven 构建时将同一文件放进后端资源，避免两份配置漂移。

- `schemaVersion: 1` 标识数据格式。
- `version` 标识内容版本，修改配置后递增。
- `aliases` 为资料字段名称到网页别名的映射，采用明确名称匹配。
- `sites` 包含 id、name、hostSuffix、有限长度 CSS 选择器和 indicators。只在域名本身或其子域名匹配时启用，不执行远程 JavaScript。

扩展先读取经校验的本地缓存，缺少或无效时使用内置规则。只有用户点击更新才向 `http://127.0.0.1:18765/api/v1/rules` 发送 GET；不携带个人资料或 Cookie。请求超时 3 秒，不跟随重定向。响应通过格式、数量、长度、字段白名单校验后才替换缓存；失败保留旧规则。

`GET /api/v1/rules` 返回 JSON、版本 ETag 与缓存头；`GET /api/v1/health` 返回服务与规则版本。没有资料写入端点。默认仅监听本机，不修改防火墙或暴露公网端口。

已有上游站点逻辑和声明式配置都需要真实页面逐站验证。发现无法识别的页面时，应使用虚构资料/脱敏结构建立回归用例，再调整配置。
